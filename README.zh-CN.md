# XTray

[English](README.md) | 简体中文

XTray 是一个轻量、便携的 Windows 托盘应用，用于运行 [Xray-core](https://github.com/XTLS/Xray-core)。相比 Xray-core 自带的简陋 Windows 运行脚本，它提供了简单的窗口和托盘操作，可启动、停止、重启 Xray，查看日志和设置登录自启，全程不显示命令行窗口。

XTray 只提供基础运行管理。Xray-core 的配置选项和参数很多，本项目不会为了覆盖这些选项而扩展为复杂的管理工具。

**XTray 仅适合充分理解 Xray-core，并能够自行维护 Xray-core 配置的高级用户。**

XTray 是一个独立项目。Xray-core 需要单独下载和更新。

## 便携使用

XTray 是一个 Windows x64 单 EXE 程序，无需安装，也无需额外安装运行库。

设置保存在 `XTray.exe` 同级的 `data` 文件夹中。若要便携使用，请将 Xray 及其配置文件放在 XTray 文件夹内，并使用相对路径。移动时请移动整个文件夹，包括 `data`，以保留设置。

移动文件夹后，如需继续使用登录自启，请从新位置打开设置，重新启用该选项。

如需运行多个独立实例，请使用不同的文件夹，并为各自的 Xray 配置不同的监听端口。每个 XTray 实例只管理一个 Xray 进程。

## 下载

- [下载 XTray](https://github.com/mclovin-2k/XTray/releases)：在 **Assets** 中选择 **XTray.exe**。
- [下载 Xray-core](https://github.com/XTLS/Xray-core/releases)：选择与你的系统兼容的 Windows 软件包（x86 或 x64）。

## 快速开始

1. 将 `XTray.exe` 放在当前 Windows 账户具有写入权限的文件夹中。
2. 将 Xray-core 软件包解压到 `XTray.exe` 同级的 `bin` 子文件夹中，保留随附文件。
3. 打开 `XTray.exe`，然后选择**文件 → 设置**。
4. 确认 Xray 程序路径（默认为 `.\bin\xray.exe`），添加配置文件（每行一个）和/或选择一个配置目录，然后点击**保存**。
5. 点击**运行**，启动 Xray。

配置文件和配置目录均无默认值。运行前必须至少选择一个配置文件或一个配置目录。可以同时使用多个配置文件和一个配置目录。

文件可以位于 XTray 文件夹之外，也可以输入相对路径。相对路径以 `XTray.exe` 所在的文件夹为基准。

如需了解如何编写配置，请参阅 [Xray 文档](https://xtls.github.io/)。XTray 不生成或编辑 Xray 配置文件。

### 为什么配置文件和配置目录可以同时设置？

Xray 原生支持同时使用多个 `-config` 参数和一个 `-confdir` 参数。XTray 保留这些能力，方便用户将配置拆分为可复用的部分，并自由选择加载方式。

例如，可以在一个目录中维护公共的日志、DNS 和路由配置，再通过文件列表选择本次需要使用的入站或出站配置。这样既能复用公共设置，也能独立维护各个部分，无需复制整套配置或手工合并文件。

XTray 将选定的路径传给 Xray，由 Xray 按照其[多文件配置规则](https://xtls.github.io/config/features/multiple.html)加载和合并。你可以只使用一个文件、多个文件或一个目录，也可以将文件与目录组合使用，按自己的配置组织方式选择即可。

XTray 先传入 `-confdir`，再按文件列表顺序传入 `-config`。参数排列不保证覆盖优先级：已核对的 Xray 版本仍会在单独文件之后合并目录配置。配置存在重叠时，请使用**Xray 工具 → 预览 Xray 配置**确认最终结果。

## 日常使用

- **运行 / 停止 / 重启**：通过主窗口或托盘菜单控制 Xray。
- **状态**：Xray 运行时，主窗口状态图标和系统托盘图标显示绿色；停止或启动失败时显示红色。
- **显示或隐藏窗口**：单击托盘图标显示主窗口。关闭窗口后，XTray 和 Xray 仍会继续运行。选择**文件 → 退出**或托盘菜单中的**退出**，即可停止这份 XTray 管理的 Xray 进程并退出 XTray。
- **配置快捷操作**：从主窗口打开已保存的配置文件、文件所在目录或设置的配置目录。
- **日志**：可查看全部日志、仅 XTray 日志或仅 Xray 日志。按钮从左到右依次为复制全部、清空日志、滚动至底部、自动换行。复制和清空作用于当前选定来源；复制包含视野之外仍保留的日志。滚动至底部按钮保持按下时，会自动跟随新输出；向上滚动会暂停跟随，滚动到底部或点击按钮会恢复。自动换行默认开启，并记住选择；切换换行不改变复制文本中的换行。日志仅保存在内存中，不保存历史日志。如需将 Xray 日志保存到文件，可使用 [Xray 内部的日志配置](https://xtls.github.io/config/log.html)。
- **语言和外观**：设置中可选择自动、英文或中文，以及浅色、深色或跟随系统的外观，还可设置日志保留行数。

如果 Xray 启动失败，请查看界面显示的错误及 Xray 输出，修正程序路径或配置后重试。

## Xray 工具

**Xray 工具**菜单使用**文件 → 设置**中已保存的 Xray 程序和配置：

- **检查 Xray 配置**：调用 Xray 的配置检查功能，显示原始输出和退出码，不启动代理服务。
- **预览 Xray 配置**：显示已保存配置来源在磁盘上的当前合并结果。此预览只读，不代表运行中进程的内存配置。
- **显示 Xray 版本**：显示实际程序路径和 Xray 的版本、构建信息，无需配置文件。

工具与正在运行的代理相互独立，同一时间只执行一个工具任务。结果窗口在输出区域上方提供**复制全部**和**自动换行**图标按钮。每次新开结果窗口时，自动换行默认关闭，仅在该窗口关闭前保留选择；关闭自动换行时可横向滚动。复制始终包含完整结果，保留原有换行。完整输出不受运行日志行数限制。关闭结果窗口会取消未完成的任务；结果只保存在内存中，关闭窗口后释放。

## 登录自启

在设置中启用**登录后自动启动 XTray 和 Xray**并保存。下次登录 Windows 时，XTray 会显示托盘图标，并使用已保存的配置启动 Xray。此设置仅对当前 Windows 账户生效。

手动打开 XTray 会显示主窗口，点击**运行**后才会启动 Xray。
